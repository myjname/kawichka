# Поставка 0.1.36 — 28 октября 2026

Исправление определения установленной Кавычки при разных представлениях одного Windows-пути. Выпуск готовится; публикация ещё не подтверждена.

Причина пользовательского сбоя 0.1.34: в current.json путь данных имеет префикс `\\?\`, интерфейс показывает обычный путь; updater сравнивал PathBuf напрямую и отключал кнопку. Ошибка сохранилась в 0.1.35. Ярлык указывал на правильный Portable.exe. Сравнение старого предиката даёт false, хотя Windows samefile подтверждает одну физическую папку.

Теперь общий `installation::same_data_path` использует существующее нормализованное сравнение полных компонентов через `transfer::owned_tail` с обязательным пустым хвостом. Поддерживаются drive/UNC и extended-формы; относительные, чужие и вложенные каталоги не совпадают. Проверки указателя установки, no-link и принадлежности данных не отключались. То же исправление применено к стартовой проверке, переносу хранилища и удалению приложения. Ограничения переноса/удаления для portable сохраняются.

Локальное подтверждение: опубликованным Setup 0.1.35 создан отдельный настоящий fixture с extended common/data. Новый updater Controller и его кнопка проверены в Slint software-окне: клик запустил реальный GitHub check, показал результат и доступную версию. Обычный и portable-контексты работают; посторонняя папка блокируется, DB и current.json неизменны. Это проверка самого UI-контроллера и pointer event, а не замена её CLI-обновлением. UNIT покрывает drive/UNC/case и точные границы каталогов. Свидетельство: `work/update-context-20261028/result-bin-01.json`.

Пользовательскую рабочую и тестовую копии в ходе исправления не меняем. Поскольку старая кнопка уже отключена, для первого перехода на исправленный выпуск понадобится отдельный запуск нового установщика с контекстом именно тестовой portable-копии. Файл запуска будет предоставлен после проверки скачанного пакета; автоматически обновлять приложение пользователя не требуется.

Локальный итог перед тегом: 203 Rust tests passed, 9 явно ignored, 0 failed (`work/update-context-tests.log`), Clippy all-targets `-D warnings`, fmt, P1 contract и public-source checks проходят. Python/backend не менялись; прежний полный Python gate остаётся отдельным свидетельством. Три UI-контекста проверены на SHA `ec8873313926d6e6b0ee07127f3adfa916fff9b50ab7fc42b306ff89da833cca`; обычный/portable получают реальный ответ GitHub, чужой путь не запускает запрос.
