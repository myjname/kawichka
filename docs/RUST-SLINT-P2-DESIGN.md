## Навигация и действия

Основная навигация: Сегодня → Расписание → Библиотека → Голос и модели → Персонаж → Настройки → Хранилище → Помощь и обновления. Узкий режим оставляет иконки с доступными именами, основной контент прокручивается, действия остаются внизу окна. Галерея намеренно перечисляет отдельные состояния для ревью; её 62 пункта не становятся 62 разделами приложения.

## Решения B03 без расширения обязательного объёма

- Имя и форма обращения — доступные поля в общем разделе и первом запуске. Сохраняются независимо от выбранного голоса.
- Категории нужны в действии «Создать партию» вместе с её количеством. Отдельная универсальная панель ключей backend не нужна.
- model_paths сохраняются для всех моделей; у выбранной модели в «Дополнительно» доступны просмотр пути/выбор подготовленной папки. Новые загрузки принадлежат общему хранилищу. Изменение одной модели не сбрасывает чужие пути.
- Число ручной партии не выдаётся за число автодня. Дневной объём считается по расписанию и лимитам повторов; статус показывает готово/нужно. Автоподготовка действует при выключенном runtime.
- Перед установкой размеры/совместимость получают из реального probe; числа в макете обозначены примерами. Переключение языка не инициирует загрузки.

## Контракт состояний и доступности для P3–P7

Экран показывает заголовок, состояние, причину и действие, а не техническую трассировку. Ошибка отличается текстом, а не только цветом. Долгая операция показывает этап/прогресс, доступность отмены и что останется после неё. Пустая библиотека предлагает рабочий путь без принудительной установки моделей. Последний резерв/личные refs не выбираются для обычной очистки.

Формы на рендерах показывают значения; редактирование настоящих полей относится к P3. Порядок Tab: навигация → подраздел → поля по визуальному порядку → действия. У полей есть постоянная подпись, доступное имя, ограничения и связанная ошибка; select/checkbox/spinbox реализуются соответствующими доступными контролами, не декоративными прямоугольниками. Длинный путь можно скопировать/посмотреть полностью; сокращение не меняет сохранённое значение.

Экран unsaved — блокирующее решение перед уходом: фоновые переходы не применяют черновик. Escape возвращает к редактированию, Enter действует по фокусу; опасное удаление не является действием по умолчанию. После отмены возвращать фокус инициатору. Сообщение маскота не забирает фокус; смена аудиовыхода не закрывает текст. Пока список/операция не готова, опасные и противоречащие действия отключены, отмена остаётся доступной, где она безопасна.

Иконки узкой навигации получают accessible label и tooltip, клавиатурный фокус остаётся видимым. В нативном интерфейсе обязательны реальный Tab-обход, Narrator, масштаб Windows/мониторы и системный Reduce Motion. Их нельзя засчитать по статичной картинке или Enter только одного демонстрационного действия.

## Проверки и граница результата

Выполнено **552 рендера для 62 состояний**. Минимальный проверенный текстовый контраст — **5,46:1**, границы контролов — **3,34:1**. Проверки компоновки и Enter прошли; fmt/Clippy design-preview прошли без предупреждений.

Полная матрица: RU/EN × Light/Dark для каждого состояния. Контрольные длинные формы дополнительно: 720×480, 150% и 200% масштаба Slint, верх/низ прокрутки и видимый фокус. Это проверка логической компоновки и пиксельного рендера, не испытание физических мониторов. Масштаб 200% для 720×480 даёт 1440×960 физических пикселей.

Рендерер отказывает при переполнении нижних действий или слишком малой области содержимого. Проверка галереи сверяет состояния/переходы, покрытие S01–S20, PNG-размеры, полный набор тем/языков, стресс-кадры и контраст из фактической палитры Slint: текст ≥4,5:1, границы контролов ≥3:1. В Slint отдельно проверяется активация главного действия Enter. Ключевые кадры дополнительно осматриваются визуально; первоначальные сбои сборки/компоновки исправлены, незавершённые прогоны не выдаются за результат.

Команды воспроизведения: cargo build --manifest-path next/Cargo.toml -p kavychka-design-preview --locked; затем kavychka-design-preview review next/crates/design-preview/review.json <новая-папка>; затем python -B scripts/build-p2-gallery.py --frames <папка-рендеров> --output <новая-галерея>. Прежняя команда overview/models/library сохранена. Проверки fmt/Clippy относятся к design-preview; тесты продукта и ML не повторяются без изменений продукта.
