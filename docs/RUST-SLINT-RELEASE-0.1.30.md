## Что осталось

Это поставка предварительного выпуска, а не принятие стабильной версии. Отложенные батарея, несколько мониторов и смена учётной записи Windows не проверялись. Целевой ноутбук, долгий прогон и остальные выпускные условия плана остаются открытыми. Два прежних Rust advisory matches не объявлены исправленными; Python-набор и его границы описаны в отчёте зависимостей. Ранее принятые пользователем группы ручного чек-листа не отменяются и не требуют повторения без конкретной причины.
