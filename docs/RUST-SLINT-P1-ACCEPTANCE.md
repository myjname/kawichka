## Изменения исходников в объёме P1

1. Строгая граница SchemaVersion: отсутствующая либо целая 0/1/2; malformed/future отклоняется. SQLite legacy user_version теперь тоже отвергает отрицательные значения.
2. Исправлена перезапись desktop-настроек назначения при завершении семантики первого импорта. Маркер legacy_keep_current_preferences сохраняет текущие настройки; для прежних preview без маркера остаётся однократное дополнение ранее не перенесённых полей. Прежняя серия не заменяется старым checkpoint.
3. Старые строки без seed получают историческое значение 42 вместо неявного Rust-default 0.
4. Добавлены семь содержательных Rust-проверок: полная полевая fixture; все shared-пары с обоими флагами/overrides/отсутствующим владельцем; malformed versions; границы SQLite/schema; архив против активного и конфликт ID; базовая форма phrases при каждом маркере 0/1/2; конфликт медиа без публикации origin. Существующая регрессия сохранения настроек усилена non-default desktop-значениями.
5. Проверка scripts/check-p1-contract.py сверяет allowlist, каталог/revisions/runtime pin, модели core, пять таблиц fixture и актуальность таблиц документа. Обычный запуск не пишет файлы и не обращается к сети/данным пользователя. Она добавлена в Windows CI; сам GitHub CI в этой работе не запускался.
