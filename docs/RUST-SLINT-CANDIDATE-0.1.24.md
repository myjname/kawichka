**Ограничение R04:** для нескольких объединённых событий применяется полный встроенный текст и системный голос Windows. Генерация специальной общей записи выбранной TTS-моделью не добавлялась. Это исключает ложную одиночную озвучку, но характерный голос в таком случае заменяется системным.

**Совместимость:** SQLite остаётся версии 3, State и профиль — версии 1; новых таблиц и индексов нет. `preparation_state.cancelled_day` хранит отмену. Типизированные `library_meta.pending_notice:<id>` сохраняют тексты архивных сообщений в одной транзакции с checkpoint. Полный профиль сохраняет их; экспорт без библиотеки исключает их. Для чтения нового профиля с такими записями нужна 0.1.24+: старый строгий reader откажет, а не молча отбросит данные. Штатный откат установки использует резерв до обновления, новые данные сохраняются отдельно по существующему механизму.
