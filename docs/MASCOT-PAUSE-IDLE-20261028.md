# Маскот: пауза, idle и обычные изображения

Пользовательские замечания 28 октября 2026: на паузе персонаж уменьшается; таймер должен появляться ниже без изменения картинки. Нужен постоянный idle. Обычные импортированные картинки не должны намеренно превращаться в pixel art. Новый пробный пользовательский питомец создаётся отдельно через явно вызванный Pets; облачная Library недоступна, пользователь разрешил сохранять весь творческий набор локально в `outputs/private`.

Локальные исправления приложения:

- Размер тела/изображения постоянен. Пауза увеличивает только высоту окна вниз для подписи времени; клетка покрывает прежнее тело. Изображение, размещение и native alpha mask используют одну квадратную область; таймер находится под ней.
- При изменении высоты окно сохраняет положение, кроме необходимого ограничения границами экрана. Параметр размера персонажа не меняется.
- После уточнения пользователя idle настраивается: «Выключена», «С паузами», «Непрерывно». По умолчанию — 5 секунд движения и 30 секунд паузы. В режиме с паузами длительности задаются отдельно: 1–300 секунд движения, 1–3600 секунд паузы. Политика общая для штатной Кавычки, GIF и атласа. Речь/подтверждение могут запустить реакцию между idle-циклами, но не обходят Off, общую паузу и системное ограничение движения.
- При загрузке старых настроек ранее выключенная анимация остаётся выключенной; поля длительности получают безопасные значения по умолчанию. Значения интервалов сохраняются при временном выборе непрерывного режима или отключении анимаций. Старое поле интенсивности сохраняется для совместимости данных, но пользователю теперь показываются режимы поведения.
- Новое одиночное изображение импортируется как smooth; исходный файл копируется без перекодирования/квантизации. Старые сохранённые пресеты и их auto/pixel/smooth-настройки не переписываются. Nearest остаётся доступен явно. Поддержка форматов по текущему decoder: PNG, JPEG, WebP, GIF, известный атлас; это не обещание любых существующих форматов.
