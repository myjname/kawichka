## Что сделано

### Генерация и среды

- Worker сообщает этапы текста, выбора подачи, освобождения текстовой модели, озвучки и публикации. Текст сохраняется до озвучки: ошибка голоса не уничтожает удачный текст.
- Runtime использует выбранную для него текстовую модель. Исправлен срочный переход с фоновой генерации: сначала завершается прежний процесс, затем стартует срочный запрос в пределах исходного срока. После срока выдаётся резерв; поздняя запись не переигрывает уведомление.
- Отмена сначала кооперативная, затем ограниченное завершение собственного дерева. При неудачном старте удаляется созданный временный payload; пользовательские записи и внешние компоненты не удаляются.
- Явная установка проверяет контрольные суммы весов, ремонтирует собственную копию, не перезаписывает внешний файл. Есть отдельное восстановление выбранной среды. Непроверенная старая собственная Python-среда сохраняется отдельно, а не используется по повреждённому маркеру.
- Начальные настройки работают без локальных моделей. Для нового выбора предложена более лёгкая Qwen3.5 4B; старый явный выбор сохраняется. Оценки памяти подписаны как приблизительные, минимальная VRAM всего каталога не объявлена измеренной.

Код: `next/worker.py`, `app/src/inference.rs`, `app/src/models_library.rs`, `app/src/bootstrap.rs`, модели и Slint-экран. Проверка фактических весов относится к Gemma 4 12B + CosyVoice 3; весь каталог не скачивался.

### Обслуживание

- Диагностика с предварительным просмотром и локальным экспортом: только разрешённые типизированные поля и объяснения RU/EN. Сырые логи, тексты, имена, пути, референсы и аудио в этот отчёт не включаются. Автоматической отправки нет.
- Обычное удаление сохраняет common, настройки, записи, модели, locator и данные восстановления. Полное требует отдельного выбора и подтверждения состава, принадлежности хранилища и повторной проверки файлов. Неизвестные файлы в корне общего хранилища блокируют полное удаление; внешние модели сохраняются.
- Если общий диск недоступен, обычное удаление допускается только без незавершённого обслуживания; полное отказывается. Пустая база взамен отсутствующей не создаётся. Занятое приложение не завершается принудительно: окно удаления показывает отказ и позволяет повторить проверку.
- Нормальный мастер регистрирует per-user запись в Installed apps независимо от галочки ярлыка. Вызов `Kavychka.exe --uninstall` запускает проверенную копию помощника вне каталога программы. Чужая запись реестра и изменённые пользователем ярлыки не удаляются.
- Portable содержит собственные program/data/setup, не регистрирует системный locator, автозапуск, ярлыки или Installed apps. При переносе всей закрытой папки собственные пути перебазируются; внешние остаются внешними.
- Обновление включается автоматически только после законченного первого запуска. Учитывается пиковое место, очистка устаревшего кандидата, повторная проверка размера/SHA/manifest непосредственно перед запуском и запрет подмены открытого Windows-файла.
- Cargo-инвентарь лицензий и найденные тексты входят в пакет. Workflow сохраняет installer/portable для проверки и не публикует release. Подпись издателя не создана.

Код: `maintenance/src/{diagnostics,removal,registration,portable,updates,windows}.rs`, `app/src/{removal_ui,data_ops,setup,updater}.rs`, сборщики пакетов.
