# Автономная разработка: кандидат 0.1.12

24 октября 2026. Пользователь отложил физические проверки и поручил продолжать разработку. Computer Use не включался; рабочая установка, тестовая копия 0.1.10, автозапуск, устройства, личная база и внешние модели не переключались. Это локальный кандидат, не stable и не публичный выпуск.

## Изменения

1. **P7, тексты лицензий.** Сборщик использует активный normal/build Cargo-граф приложения и launcher для Windows x64, включая build tools. Неактивные optional/dev-пакеты больше не выдаются за состав выбранной сборки. Для 11 crates добавлены 27 оригинальных upstream-файлов с закреплёнными Cargo checksum, commit публикации, URL и SHA. Сохранены дополнительные AUTHORS/Chromium notice AccessKit. Изменение версии или содержимого supplement вызывает отказ. Пустые/недопустимые/выходящие за папку файлы и junction отвергаются. NOTICE без лицензии не удовлетворяет проверке. Сборка по умолчанию останавливается при недостающем тексте; разрешающий отчёт флаг не используется упаковщиком.
2. **P8, программный кадр при ML.** Добавлен явный `--measure-frames`: настоящий AppWindow, обычный settings-service и worker, отдельная библиотека, выбранные внешние компоненты только для чтения. Фоновый поток ставит навигацию в очередь Slint; измерение заканчивается после layout/render полного кадра 1100×780 в памяти. Пять страниц, 60 секунд прогрева, 50 мс между запросами, один неподтверждённый запрос. Партия трёх фраз с озвучкой и отмена следующей задачи; минимум 300 кадров при активной генерации. Сохранены все отсчёты и SHA EXE. Нативных окон, desktop input и playback нет. Это шире прежнего callback-замера, но не проверка compositor, физического ввода, покоя или целевого ноутбука.
3. **Задания для еды.** Первый полный прогон 0.1.11 остановился на шести отклонённых вариантах для обеда. Отдельная проба показала естественные «поешь»/«перекуси», которые не удовлетворяли строгому разделению приёмов пищи. Русское и английское задания теперь прямо требуют назвать соответствующий приём пищи. Проверка темы/повторов не ослаблена, готовый текст вместо модели не подставляется. Настройки пользователя не меняются.

Код: `next/{Collect-notices,Test-notices}.ps1`, `next/tools/Notice-functions.ps1`, `next/licenses/supplemental/`, `app/src/{frame_measurement,service,models_library,setup}.rs`, `backend/kavychka_local/character.py`. В CI добавлены проверки сборщика перед упаковкой.

- Публичный состав проверен: итоговые 360 выбранных исходных файлов, без распознанных шаблонов ключей/личных референсов; не аудит всей истории или всех возможных секретов. Шесть прежних изменённых файлов пользователя сверены по SHA и сохранены. `autonomous-public-final.log`.
- Release-пакет 0.1.12 собран offline, source-freeze и package allowlist/integrity gate пройдены. `autonomous-package-02.log`.
