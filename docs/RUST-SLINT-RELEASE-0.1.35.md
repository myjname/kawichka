# Поставка 0.1.35 — 28 октября 2026

Подготовлен выпуск согласованных изменений интерфейса, персонажей, библиотеки и текстовой поддержки. Пользователь разрешил commit, push и стабильный релиз; обновление установленной Кавычки выполняет самостоятельно. Эта запись до появления итоговых SHA/CI не означает завершённую публикацию.

- Общая сетка полей и галочек, связанные пояснения, компактные действия, вкладки компонентов/пресетов.
- Импорт ZIP сразу применяет и сохраняет персонажа; посторонние черновики сохраняются, при ошибке БД нет ложного применения. Раздельные правки голоса/характера/внешности остаются доступны.
- В библиотеке иконки с подсказками, статусы, актуальный список и история, удаление с сохранением контекста для защиты от повторов.
- На «Сегодня» выбранная внешность и одна текстовая фраза без кнопок/озвучки, редкая смена до/после 12:00 по поясу приложения. Отдельный текстовый список поддержки, встроенный резерв и фоновая генерация.
- Nearest для pixel art при произвольном размере, общая геометрия изображения/клика, пропорциональная клетка и отдельное место таймера.
- Исправлены подписи Slint, RU/EN динамических списков и видимость результата проверки обновлений.

До выпуска локально: 201 Rust tests passed, 9 явно ignored; 150 Python tests passed без skips; Clippy all-targets `-D warnings`, fmt и public-source/P1 checks проходят. Реальные software callbacks, keyboard/pointer, импорт/экспорт/защита удаления, отказ SQLite и сохранность черновика проверены на собственных данных. Широкая матрица 288 снимков страниц и повтор затронутых состояний, 30 сцен маскота. Gemma 4 12B CPU создала четыре текста без аудио/скачивания/изменения весов. Подробности: [единый план](UX-AND-MODEL-INSTALL-FIX-PLAN.md).

Нативная ручная, Narrator и отложенная аппаратная приёмка остаются открытыми. Повторная полная холодная загрузка моделей в этом выпуске не выполнялась. Пользовательские модели, среды, записи, пресеты и установленные копии в ходе подготовки не изменяются; личный Sylus-пресет в Git и релиз не входит.
