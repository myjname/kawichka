# Поставка 0.1.31 — 28 октября 2026

**Опубликован предварительный релиз 0.1.31 и обновлена существующая пользовательская установка.** [GitHub Release](https://github.com/myjname/kawichka/releases/tag/next-v0.1.31). Пользовательская приёмка нового интерфейса выполняется после обновления; стабильный канал не переключался.

## Исходники и проверки

Source/tag `next-v0.1.31`: `d56ed69f640160db507de30057ad266b8e010c6b`, ветка `TechArt/compact-ui-model-setup`. Другие ветки не изменялись. Коммит содержит компактный UI, сквозную установку выбранных моделей и сред одной кнопкой, единый блок задач, объединённые наборы персонажа, исправления масштабирования/путей и CPU CosyVoice. Личные пресеты, референсы и профиль в Git и артефакты не включены.

[Rust CI](https://github.com/myjname/kawichka/actions/runs/40658947513) и [Windows regression CI](https://github.com/myjname/kawichka/actions/runs/40659067140) прошли на этом SHA. Перед публикацией исправлены два ложных срабатывания проверки публичных исходников: точечно разрешены два Rust-модуля в `storage/src/presets`, а тестовый маркер неизвестного секретного поля заменён короткой фиктивной строкой. Проверка настоящих ключей не отключалась. Локальный повтор Cargo-теста не запустился из-за отсутствующего offline index; тесты исходного коммита затем прошли в GitHub CI. Ранее проверенный локальный кандидат описан в [плане исправлений](UX-AND-MODEL-INSTALL-FIX-PLAN.md).

Скачанные из draft Setup, Portable и SHA256SUMS сверены с GitHub digest, envelope и всеми 530 файлами payload. Python-файлы сопоставлены с исходниками с нормализацией переводов строк; для двух штатно объединённых модулей использован тот же проверенный `Bundle-backend.ps1`. На скачанном `app.exe` прошли software Slint controls и проверка полного набора персонажа. На отдельном синтетическом профиле прошли install 0.1.30 → update 0.1.31 → rollback, сохранение настроек, строк и аудио, а также отдельное сохранение новых данных при откате.

Начальные ошибки локального QA не засчитаны как успешные: проверяющий скрипт не учитывал штатный bundling Python; затем сценарий обновления был запущен без заполненного профиля; в следующей попытке сам подготовщик fixture оставил открытое SQLite-соединение. После исправления условий QA и закрытия соединения финальная проверка прошла. Производственный установщик ради обхода этих ошибок не менялся.

## Установленная копия и сохранность

Программа: `%LOCALAPPDATA%\Programs\KavychkaNext`; общая библиотека и модельные пути не менялись. Перед обновлением создан частный SQLite-backup и побайтово проверенная копия файлов профиля в игнорируемой `work/publish-20261028/before-update`. После обновления подтверждены равенство настроек и всех 69 строк библиотеки, сохранность 86 прежних файлов профиля и SHA обеих выбранных моделей. Весов повторно не скачивали, стабильный корневой launcher не заменялся; все 530 файлов новой версии сверены с манифестом, Installed apps показывает 0.1.31.

Защита от AppData-редиректа отказала запуску установщика из унаследованного контекста Codex до изменения установки. Обновление выполнено через настоящий desktop Explorer COM-контекст; защита не отключалась. Физический путь базы подтверждён как пользовательский AppData, без нового профиля в кеше Codex.

Приложение оставлено закрытым: библиотека ещё помечена предыдущим днём, и обычный запуск может выполнить установленную пользователем ежедневную очистку старого аудио. Обновление само записи не удалило; резерв сохранён. Автоматическая публикация не заменяет пользовательскую приёмку нового UI.
