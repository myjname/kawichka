# 0.1.40 — разборчивая CosyVoice, подробности и выделение

28 октября 2026. Стабильный выпуск: https://github.com/myjname/kawichka/releases/tag/next-v0.1.40. Исходный commit: `48fad8a8eb87674a2e3350b97feda1076a8a4e34`, тег `next-v0.1.40`, ветка `TechArt/compact-ui-model-setup`. Кандидат 0.1.39 не публиковался: перед публикацией обнаружен и исправлен дополнительный случай с двумя быстрыми кликами «Все».

## Изменения

- Исправлена потеря контекста CosyVoice: маска внимания теперь включает закешированные предыдущие токены и текущие токены. Сохранены существующие версии Torch/Transformers и модели; переустановка среды не требуется. Старые cache keys озвучки не используются при переозвучке; старые файлы при обновлении не удаляются.
- Добавлена независимая локальная проверка распознанной речи относительно заданного текста, с проверенным по SHA checkpoint Whisper base и порогом CER 0.35. Ожидаемый текст не подаётся ASR как подсказка. Инструмент разработчика работает офлайн, в установщик дополнительная ASR-модель не входит. Процедура: [SPEECH-RELEASE-CHECK.md](SPEECH-RELEASE-CHECK.md).
- Подробности задачи переведены в PopupWindow: библиотека не закрывает их своим слоем; клики внутри окна не выбирают фразы под ним.
- Выделение получило revision: запоздалые ответы не сбрасывают и не восстанавливают выбор после его изменения и возврата к тем же ID. Список поддержки сохраняет VecModel и фокус checkbox при обновлении. «Все» использует фактическое checked-состояние, поэтому второй быстрый клик отменяет ожидающее выделение.

Нейронная приёмка использовала **next/worker.py из этого пакета**, реальный Engine.speech, CosyVoice и сохранённые нормализованные FLAC. В отдельной библиотеке с локальными копиями двух референсов получены одна русская запись на CPU и две русские плюс одна английская на CUDA; две подачи. Все четыре записи распознаны новым публичным инструментом, максимальный CER **0.12150** при пороге 0.35. Старая запись с бессвязными слогами дала `passed: false`, код выхода 1. Снимок `release-library/history-details.png` осмотрен. Также прошли существующие проверки feedback и реального контекста обновления в software-окне.
