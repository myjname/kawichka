# Автономная разработка после 0.1.10

24 октября 2026. Основание: пользователь отложил ручные проверки и поручил поставить цель и продолжать разработку без его участия.

Цель — закрывать доступные инженерные остатки актуального аудита P6–P8, сохраняя настройки, модели, записи и прежние изменения. Сначала: комплектность уведомлений о зависимостях и проверок пакета P7; затем измерение программного UI-кадра во время настоящей локальной генерации P8. Найденные ошибки исправляются и проверяются, результаты привязываются к исходникам/EXE и методу измерения. Отсутствующая аппаратура и ручной тест не выдаются за успешную проверку.

## Порядок работы и критерии результата

1. Проверить сборщик уведомлений: он должен описывать граф фактически выбранных для Windows пакетов приложения/launcher, не терять нужные license/notice и явно отмечать нерешённое. Дополнить недостающие тексты из проверяемых первичных источников с закреплёнными версиями/происхождением. Проверить сборщик на реальном offline Cargo-графе и отрицательных случаях; выполнить сборку пакета с инвентарём. Это техническая комплектность, не заключение юриста о выпуске.
2. Добавить проверку UI во время реальной генерации без окон на рабочем столе: путь от поставленного в очередь действия до полностью рассчитанного и отрисованного в памяти Slint-кадра, а не только callback. Использовать уже имеющиеся выбранные веса/среды и отдельную синтетическую библиотеку; не скачивать весь каталог. Отделить headless программный кадр от физического ввода/экранного compositor и от отсутствующего ноутбука 8 ГБ. Собирать память/CPU/отмену и достаточно отсчётов; при найденной задержке исправлять причину.
3. По результатам выполнить адресное ревью, необходимые Rust/Python/сборочные проверки и сформировать новый проверяемый кандидат и отчёт. Оценить остальные доступные проверки P6–P8; не заканчивать работу только потому, что ручная часть отложена.
4. Актуализировать статус этапов и остатки: реализовано, проверено конкретным методом, требует оборудования/пользователя/чистой системы, не выполнено. Полный P4/P8 и stable не объявлять закрытыми по частичным свидетельствам.

## Ограничения

- Computer Use не включать; не создавать мешающих окон или выполнять lock/sleep/session/audio-device действия. Ручные вопросы до возвращения пользователя не задавать.
- Не изменять рабочую установку, автозапуск, системные настройки и активную личную базу. Все испытания — под `work/` на собственных данных; имеющиеся внешние модели/среды только повторно использовать.
- Не публиковать release, не менять доступ GitHub и не отправлять личные голоса, референсы, диагностику или ключи. Семь прежних изменённых файлов текущей итерации сохранять по исходным отпечаткам.
- Физический допуск кликов P4 и административный ENOSPC P5 отложены. Предыдущие успешно выполненные ручные проверки сохраняют свой реальный scope/build.

## Состояние цели

Итерация по поручению пользователя: разобрать два редких выброса до 740 мс, не вовлекая пользователя в ручные проверки. Критерий: инструментированный замер CPU/ожидания UI, локализация причины по воспроизводимому свидетельству, минимальная адресная правка и повтор настоящего ML-прогона/необходимых регрессий. Отсутствие нового выброса само по себе не считается объяснением старого. Рабочая установка и личные данные сохраняются; Computer Use не включается.

**Итерация завершена в проверенном программном scope:** [отчёт 0.1.18](RUST-SLINT-UI-STALLS-20261024.md). Диагностика установила участие DPC/CPU0: сопоставлены CPU-flat фазы UI, номер ядра, синхронные PDH-показания до 100% и обратный контроль размещения. Приоритет ML и одна ideal hint по отдельности были недостаточны; неудачные прогоны сохранены. Финальные CPU Sets проверены двумя настоящими ML-прогонами: 4 700 активных кадров, p95 10,207 мс, максимум 14,579 мс, 0 >100 мс, шесть записей, отмена 310/546 мс. Системная DPC-нагрузка при проверке сохранялась. Конкретный драйвер не установлен; WPR не получил системного права профилирования. Установщик/portable, 146 Rust/20 Python-тестов, Clippy и целостность пакета проверены; семь прежних файлов сохранены. Дополнительно исправлен и проверен настоящий CPU-сбой CosyVoice при использовании CUDA-среды.

Предыдущая итерация: [кандидат 0.1.12 и точные свидетельства](RUST-SLINT-CANDIDATE-0.1.12.md). Сборщик P7 завершён в техническом scope: 263 пакета, 495 файлов, 0 пропусков; отрицательные/интеграционные проверки и комплект installer/portable пройдены. Замер P8 выполнен на настоящей ML-задаче: три записи, 3 859 активных кадров, p95 9,989 мс, отмена 568 мс. Исправлено несогласованное задание для еды, обнаруженное первым неудачным прогоном. Общие проверки, software UI и настоящие update/rollback сохранности тестовых данных пройдены.

Полная стабильность и вся миграция не объявлены достигнутыми. Обход длинного хвоста P8 подтверждён в указанном безоконном сценарии; нативная заметность/другие топологии, суточная/аппаратная квалификация остаются открытыми. Физические P4 и административный P5 отложены. Остальная выпускная матрица приведена в отчёте. Никакие оставшиеся проверки не помечены успешными из-за отсутствия ответа пользователя. После ответа о приоритете дополнительные оптимизации этого хвоста не продолжаются: дальнейший приоритет — сохранность, установка/обновления и основные напоминания.

Системный `create_goal` отказал: в чате остаётся незавершённая цель P4 со статусом blocked. Она не помечается complete ради обхода ограничения; этот файл фиксирует новое поручение и результат итерации. Техническое ограничение goal API не останавливало разработку. Токеновый бюджет пользователем не задан.
