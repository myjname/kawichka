# Подключение моделей и библиотеки к Rust + Slint

Проверено 23 октября 2026 года на текущем компьютере Windows. Этап завершён как отдельная рабочая версия для проверки; полная миграция и выпуск приложения не объявляются завершёнными.

## Цель и результат

Цель этапа: подключить библиотеку и отдельные ML-движки, подхватить существующие настройки, тексты, аудио и пути моделей без повторного скачивания весов; сохранить исходную установку и довести операции до воспроизводимой проверки Windows.

В новой версии работают:

- Первый безопасный импорт прежней библиотеки и разрешённых настроек, копирование аудио/пресетов, сохранение истории и прежних статусов. Повторный запуск не импортирует их заново и не сбрасывает настройки Rust-версии.
- Раздельные списки текстовых и голосовых моделей, установленность и пути. Все варианты каталога одновременно не скачиваются. Существующие веса и совместимые среды используются по прежним путям.
- Реальные генерация текста, озвучка, выбор подачи и голосового референса через отдельный Python-процесс. Rust остаётся единственным владельцем SQLite; текстовый движок выгружается перед запуском голосового.
- Настройки персонажа, голосового профиля, подач, количества, runtime и подготовки дня. Старый пользовательский персонаж сохраняется в личных данных; в исходниках только нейтральная «Кавычка».
- Прослушивание, одобрение/исключение, ручная генерация, подготовка дня, переозвучка одной записи или сегодняшних текстов без замены ID/текста, отмена и ZIP с текстами/аудио.
- Автоматическая подготовка дня с учётом расписания/питания/паузы, ограниченные повторы неудачных попыток и сохранение частичного результата. Runtime ждёт по сроку события, затем использует готовый либо встроенный вариант.
- Базовые встроенные фразы, голос Windows и прослушивание готовых FLAC без Python. Встроенный банк конечен; новые творческие тексты требуют модели.
- Отделение старого дневного аудио от активной библиотеки с копией в карантине; история текстов остаётся. Промежуточное аудио принятых заданий очищается внутри собственной папки jobs. Референсы не относятся к дневной очистке.

Это рабочая копия, а не синхронизация двух версий. После первого импорта новые изменения старой WinForms-версии сюда автоматически не подтягиваются. Исходные данные и общий указатель хранилища не переключались.

## Запуск

Закройте старую «Кавычку» перед первым импортом и запустите [next/Start-preview.bat](../next/Start-preview.bat). Корневой START.bat по-прежнему запускает WinForms.

Launcher читает прежний Kavychka-storage.json в LocalAppData, а при его отсутствии — стандартную папку Kavychka. Рабочие данные новой версии находятся в work/slint-library-user-preview. Для нестандартного источника:

```powershell
.\next\Start-preview.ps1 -LegacySource "E:\MyLibrary"
```

Путь условный. Не удаляйте work/slint-library-user-preview, если хотите сохранить изменения новой версии. На чистом клоне нужны Rust MSVC и C++ Build Tools; уже собранная подходящая версия запускается без пересборки. Установщик без средств разработки остаётся следующим этапом.

В первом JSON UI поле recording_preview_started_and_finished ошибочно читало внешнюю копию переменной таймера; условие фактического завершения уже проверялось внутри callback. Для воспроизведения проверки установленных моделей:

```powershell
.\next\Verify-models.ps1 -Source "E:\MyLibrary" -Offline
.\next\Start-preview.bat -Offline -Verify -VerifyAudio
```

Первый сценарий требует совместимые установленные Gemma/CosyVoice и их среды, закрытый источник и интерактивную Windows-сессию. Он создаёт новую частную копию, генерирует и воспроизводит звук. Веса не загружает. Второй использует синтетические данные. Ограниченная среда Codex не допускает регистрацию настоящего трея; нативная проверка выполнена вне этого ограничения, обычному приложению права администратора не требуются. Slint пишет предупреждение о своём RGBA-значке; рабочий трей реализован отдельным Win32-адаптером и подтверждён нативным сценарием.

## Оставшиеся границы

- Полная миграция P1/P5 и набор S01–S20 не закрыты. Старый checkpoint серии напоминаний, произвольные именованные часовые пояса, визуальные пресеты и часть расширенных настроек сохранены в разрешённом исходном снимке, но ещё не полностью активированы новым приложением. Не следует считать сохранённый файл доказательством перенесённого поведения.
- Реально запущены текущие Gemma/CosyVoice и голоса Windows. Остальные пункты каталога не скачивались и не прогонялись. Загрузка выбранных новых весов и llama-runtime предусмотрена; новая голосовая Python/Cosy-среда требует следующего этапа. Исходная установленная среда автоматически не обновляется. Многогигабайтная новая загрузка не проверялась.
- ZIP здесь содержит фразы и аудио. Это не полный переносимый архив настроек/пресетов с восстановлением; ему пока нужна установленная Python-среда. Импорт произвольных новых голосовых/визуальных пресетов и полноценное управление ими остаются открыты.
- Карантин имеет фиксированный безопасный предел 2 ГБ; при его превышении очистка останавливается с ошибкой. Автоматическое удаление карантина по 7 дням и настройка лимита ещё не реализованы. Полная политика двух версий/отката относится к обновлению.
- Установщик, автоматическое обновление, откат, переключение общего хранилища и распространение остаются P7. Старую установленную версию этот этап не заменяет.
- Нет проверки на реальном ноутбуке 8 ГБ без GPU, физического отключения наушников, полного современного Windows DND, всей матрицы DPI/нескольких мониторов/доступности и суточного прогона.

Следующий согласуемый этап должен закрывать оставшуюся семантику переноса и подготовку установки/обновления; этот отчёт не меняет требования исходного плана и не заменяет его критерии готовности.
