# Выпуск и подпись обновлений

Автообновление принимает только релиз, у которого рядом с `Kavychka-Next-Setup.exe` лежат `update-manifest.json` и `update-manifest.json.minisig`. Подпись ставится на компьютере владельца: секретные ключи minisign не хранятся на GitHub. Публичные ключи лежат в `next/update-keys/` и вшиты в приложение (`TRUSTED_KEYS` в `next/crates/maintenance/src/updates.rs`, соответствие проверяет тест).

## Порядок выпуска

1. Поднять версию, влить изменения в `main`, поставить тег `next-vX.Y.Z`. CI (`verify` на Windows и `portable-core` на Linux) собирает кандидат и создаёт **черновик** релиза. Черновик не создаётся, если не прошёл любой из двух заданий.
2. Скачать `Kavychka-Next-Setup.exe` из черновика.
3. Подписать на своём компьютере:

   ```powershell
   .\next\tools\Sign-release.ps1 -Setup .\Kavychka-Next-Setup.exe -Version X.Y.Z -SecretKey $HOME\kavychka-keys\kavychka.key
   ```

   Скрипт создаёт `update-manifest.json` (версия, имя файла, размер, SHA-256), подписывает его и сразу проверяет подпись публичным ключом из репозитория.
4. Загрузить `update-manifest.json` и `update-manifest.json.minisig` в черновик.
5. Проверить, что в черновике три файла установки и два файла подписи, и опубликовать релиз. Без файлов подписи приложение релиз не предложит.

## Запасной ключ

Если основной ключ потерян, подписывайте запасным: добавьте `-SecretKey` запасного ключа и `-PublicKey .\next\update-keys\kavychka-backup.pub`. Оба публичных ключа уже вшиты в приложение. После использования запасного ключа создайте новую пару и выпустите версию с обновлённым списком `TRUSTED_KEYS`.

## Что проверяется автоматически

- Тесты `updates.rs`: полный путь от списка релизов GitHub до проверки подписи (подмена хэша, отсутствие подписи, чужой ключ, правка манифеста, откат версии), и совпадение файлов в `update-keys/` со вшитыми ключами.
- Подпись и подтверждение реальной загрузки с GitHub вручную: установите предыдущую версию и проверьте обновление на подписанном черновике (до публикации обновление через API не видно, поэтому проверяйте сразу после публикации на тестовой машине).
