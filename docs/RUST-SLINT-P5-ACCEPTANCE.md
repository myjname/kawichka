# P5: данные — реализация и проверенный остаток

Дата работы: 23–24 октября 2026. Поручение: перейти к P5 по аудиту; физические проверки P4 оставить открытыми. [Цель](RUST-SLINT-P5-GOAL.md). **P5 пока не закрыт целиком: настоящий файловый ENOSPC требует последнего отдельного прогона с административным доступом.** Успешный `SQLITE_FULL` не заменяет этот прогон.

## Что реализовано

| Область | Поведение |
|---|---|
| Полный профиль B07 | Data-only ZIP v1 с SHA-256/размерами/версией схемы, настройками и State, библиотекой/историей/claims, независимыми пресетами, медиа, санированным legacy-снимком. До экспорта выбираются библиотека/история и сгенерированное аудио; показываются состав и временный пик. Веса, среды, код, recovery/quarantine, исходный settings.json/capture и частные логи исключены |
| Проверка и восстановление | Изолированная распаковка, ограничения размера/числа файлов, проверка хешей, схемы SQLite и ссылок → сводка → явное применение → проверенный резерв → публикация новых файлов и одна транзакция SQLite. Чужой SQL не исполняется. Неизвестный формат/схема отвергаются |
| Чистая установка | Восстанавливаются совместимые настройки/состояние/отбор. Указатели хранилища и действующий лимит резервов остаются локальными. Установочный probe не создаёт пользовательские настройки из пустых defaults; мастер предлагает восстановление до первого сохранения. Речь автоматически не запускается |
| Непустой профиль | Текущие настройки, состояние, исключения и конфликтующие Phrase ID сохраняются. Недостающее добавляется; конфликтующие пресеты/медиа получают другие ID/имена, импортные ссылки перепривязываются. Входящий конфликтующий снимок и таблица соответствий остаются архивными. Повтор того же архива — без дубликатов |
| Перенос B08 | В установленной версии: новая отдельная папка, оценка состава/пика/места, короткое завершение приложения, отдельное окно копирования с отменой, проверенная копия, журнал, затем смена private current/locator. Всё собственное общее хранилище, включая модели/среды, копируется; внешние пути остаются внешними. Исходник не удаляется. До commit — откат указателей, после — завершение перехода. Старый путь запуска следует к новым данным; отсутствие нового диска не создаёт пустую библиотеку |
| Учёт места | Разбивка на модели (включая настроенные внутренние пути), среды, записи, пресеты, кеш, загрузки, резервы, карантин, архивы, журналы, БД/прочее; итог и необходимое свободное место. Веса не скачиваются заново |
| Резервы B15 | Общий лимит program recovery + data recovery + quarantine. Версии и порядок переходов заданы индексом; максимум две версии / 7 дней, защищены текущий и последний пригодный резерв. Неизвестное/повреждённое молча не удаляется. Перед восстановлением создаётся отдельный проверенный профильный резерв; его удаление не подменяется политикой двух версий программы |
| Интерфейс | Одна операция на выбор: экспорт / восстановление / перенос. Фоновые копирование/хеширование/ZIP, прогресс/отмена, явное применение. Профильные операции удерживают ML/очистку, готовые напоминания продолжаются. При переносе приложение явно закрывается до копирования; окно переноса сообщает об этом. RU/EN и темы; базовый режим без Python |

Код: `next/crates/storage/src/profile/`, `storage/src/transfer.rs`, `maintenance/src/relocate.rs`, изменения `maintenance/src/install.rs`, `app/src/data_ops.rs`, `app/src/transfer_ui.rs`, `app/src/service.rs`, `app/ui/app.slint`. Старые незавершённые изменения приложения не коммитились и не сбрасывались.

Новые данные не одобряются и не расходуются восстановлением. Исходные записи сохраняют ID/текст/статусы; временные диалоги и preview не считаются воспроизведением. Старые `normalized`, `cache_key`, plans/preparation остаются в архивной части, а не маскируются под активную Rust-модель.

Дополнительные регрессии: co-located legacy-библиотека → перенос → следующий update-probe → rollback; directory-путь Origin.snapshot, нормализация Windows-путей и связанный legacy hint проверены. После явного восстановления профиля без active Origin старый hint не запускает bootstrap повторно. Настоящий source-mismatch по-прежнему отвергается. Новая прямая dev-зависимость maintenance-тестов использует уже закреплённый rusqlite; в Cargo.lock добавлена только запись зависимости, версии пакетов не обновлялись.

## Что остаётся открытым

1. **B14 / P5: настоящий файловый ENOSPC.** [Скрипт](../scripts/check-p5-full-volume.ps1) и opt-in тест `profile::full_volume_tests::actual_virtual_volume_full_during_zip_and_restore_is_recoverable` готовы. PowerShell разобран, `-PlanOnly` пройден, отрицательная проверка отвергла обычный E: до обращения к fixture. VHDX не создавался и не форматировался: даже вне песочницы токен не Administrator. Успех полного прогона может подтверждать только `full-volume-*/result.json`, а не наличие кода теста.
2. Физические проверки P4 (ввод/lock/sleep/audio/power) по просьбе пользователя остаются открытыми. Проверка переносимого носителя физическим отключением, всех системных переходов, полной доступности, суток работы, чистой машины и целевого ноутбука не проводилась; соответствующие эксплуатационные строки P7/P8 не закрываются этим документом.
3. Новые обычные Open/Save ZIP dialogs подключены; в нативном прогоне путь вводится через свойства/действия приложения. Ручной выбор файла системным диалогом и весь keyboard/a11y путь не объявляются проверенными.

Для администратора на этом рабочем месте, после проверки плана:

```powershell
& 'E:\Kawichka\scripts\check-p5-full-volume.ps1' -PlanOnly
& 'E:\Kawichka\scripts\check-p5-full-volume.ps1'
```

Вторую команду запускать в PowerShell от администратора. Сценарий привязан к SHA конкретного тестового EXE, создаёт только новый 128 МиБ VHDX под `work/`, проверяет соответствие image → новый FileBackedVirtual disk → partition перед форматированием. После прогона отключает только этот образ, сохраняя образ, план, журналы и результат. Изменение или пересборка тестового EXE требует обновить проверенный descriptor. Это инструкция к оставшейся проверке, а не утверждение об её успехе.

## Статус цели

Реализация P5 и доступные безопасные проверки выполнены; полное закрытие этапа ожидает внешнего доступа для ENOSPC. Настоящая установка пользователя, системные указатели, библиотека на C:, модели и P4-физика не переключались. Коммит/push/публикация не выполнялись. Системный счётчик цели по-прежнему занят незавершённым P4; он не помечался complete для обхода ограничения.
