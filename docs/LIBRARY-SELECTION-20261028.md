# Библиотека: закреплённые действия, отдельный список и массовый выбор

Запрос пользователя 28 октября 2026: иконки навигации и действий с подсказками, неподвижная верхняя панель, отдельная прокрутка строк, выделение и выбор всех, действия над выделением; в истории/поддержке только удаление; убрать линию, пересекающую строки.

Локально реализовано:

- Панель с категориями, стрелками страниц, счётчиком, легендой статусов по наведению и действиями не входит в прокручиваемую область. Прокручивается только список. Настройки новой партии открываются отдельной панелью.
- Все действия списка представлены иконками с tooltip и accessible-label. Полные тексты видны прямо в строках, без отдельной кнопки раскрытия. На строке остаются чекбокс и индикатор статуса.
- Выбор строк хранится только в памяти UI, переживает смену страницы и сбрасывается при переходе в другую категорию/новый день. «Все» выбирает всю категорию, включая другие страницы, а не только загруженные50строк. Поддерживается Ctrl+A при фокусе внутри библиотеки.
- Актуальные: оставить, исключить, переозвучить, экспортировать и удалить выделенные. Для прослушивания нужно выбрать одну фразу; остановка речи остаётся отдельной общей командой. Подготовка дня и новая партия создают новые строки и не требуют выделения.
- История/поддержка: только удаление выделенных; навигация/чекбоксы остаются. Запрет переозвучки/отбора этих групп дополнительно проверяется backend, а не только видимостью иконок.
- Массовое удаление подтверждается с количеством строк и снимком выделения. SQLite проверяет существование всех ID и применяет удаление/отбор транзакционно: неизвестный ID или ошибка на одной строке не оставляют частично изменённый набор. Тексты, контекст защиты от повторов и факты проигрывания сохраняются.
- Удалённая поддержка сохраняется для контекста, не заполняется заново в тот же день и может стать пустой. На новый день создаётся новый список. Удаление не запускает модели или звук.
- Разделитель строки имеет явную координату у нижнего края; статус расположен в отдельной правой области. Линия больше не проходит через текст.
