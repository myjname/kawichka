# Сравнение оболочек Кавычки

Изолированные прототипы. Основное приложение, его хранилище и модели не используются.
Источники: Avalonia 12.1.4 / .NET 10, Slint 1.18.1 / Rust stable.
Оба пакета собираются в Release. Зависимости и промежуточные файлы остаются на E:.

Общие сценарии:
- одинаковый PNG-маскот 150×170, прозрачность, фоновые анимации до 30 FPS;
- одинаковый небольшой bubble с подтверждением и остановкой;
- окно настроек: обзор, расписание, библиотека, модели; светлая/тёмная/системная темы;
- общая модель библиотеки из 10 000 записей, в интерфейсе одна страница из 50;
- отдельный одинаковый Python-процесс для синтетической нагрузки, прогресса и отмены;
- единый протокол управления для воспроизводимых измерений без движения курсора
  и ввода в приложения пользователя;
- одинаковый Windows-адаптер ограничивает область маскота альфа-маской, включает
  no-activate/toolwindow/topmost. Это не второй движок отрисовки.

Измерения: запуск процесса до готовности окна, Private Bytes и working set дерева
процессов, CPU/логические ядра, round-trip команд в UI, задержки event loop,
открытие/закрытие окон, отмена и завершение дочерних процессов, размеры пакетов.

Ограничения заранее: замеры проводятся на доступном компьютере, не автоматически
на ноутбуке 8 ГБ. Синтетическая нагрузка не доказывает скорость реальных моделей.
Программные проверки собственных окон не заменяют физические клики, реальную
смену мониторов/DPI, эксклюзивный fullscreen и 24-часовой прогон.
