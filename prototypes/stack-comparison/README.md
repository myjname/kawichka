# Кавычка: два прототипа оболочки

Это измерительный стенд, а не новая версия приложения и не финальный дизайн.
Основная Кавычка, модели, настройки и пользовательская библиотека не используются.

## Запуск готовых прототипов

- `START-SLINT.bat` — Rust + Slint 1.18.1.
- `START-AVALONIA.bat` — C# + Avalonia 12.1.4 + .NET 10.0.13.

Обе версии уже собраны в `artifacts/`. Окно настроек открывается нажатием на маскота.
Кнопка «Закрыть прототип» на странице «Обзор» завершает процесс и его фоновую задачу.
Закрытие только окна настроек оставляет маскота. Можно запустить обе версии вручную
для визуального сравнения; измерения следует выполнять последовательно.

Для кнопки фоновой нагрузки подготовлен отдельный встроенный Python 3.12.10 в
`artifacts/python`, без pip, моделей и сторонних библиотек. Он проверен SHA-256.
Установка Python в Windows и наличие Codex для запуска готовых прототипов не нужны.
Сам GUI не запускает Python, пока не нажата кнопка нагрузки.
Нужная Rust-прототипу VCRUNTIME140.dll также включена рядом с EXE, из проверенного
embedded-дистрибутива Python. Состав импортов проверен dumpbin.

## Что реализовано

- Один общий прозрачный PNG-маскот 150×170 и анимация с интервалом 33 мс.
- Сообщение с подтверждением, окно настроек, четыре раздела, светлая/тёмная темы.
- Библиотека: 10 000 строк в модели, 50 видимых строк на странице.
- Одинаковая отдельная синтетическая задача: два потока SHA-256, общий буфер 32 МиБ,
  прогресс и отмена. Это не измерение скорости реальных LLM/TTS.
- Один и тот же алгоритм Windows-адаптера на обоих языках: no-activate, toolwindow,
  topmost, область окна по общей альфа-маске и защита флагов от перезаписи backend.
- Команды стенда через stdin/stdout; управление не двигает курсор и не вводит
  клавиши в приложения пользователя.

Озвучка, расписание, сохранение настроек, обновление, импорт пресетов и модели
в этих прототипах не реализованы. Их кнопки/поля показывают предполагаемый тип
интерфейса, а не выполнение функций полной Кавычки. Кнопка «Стоп голос» — заглушка.
Перетаскивание маскота, клавиатурная доступность и реальная смена темы Windows
ещё не прошли пользовательскую проверку.

## Сборка из исходников

Нужны .NET SDK 10.0.100 (или совместимый patch), Rust stable MSVC и C++ Build Tools.
PowerShell:

```powershell
./build.ps1
```

После первой подготовки можно использовать `./build.ps1 -Offline`.
NuGet/Cargo и промежуточные файлы находятся в `../../work/stack-comparison-20261022`.
Веса моделей не скачиваются. При отсутствии кэша `prepare-worker.ps1` скачивает
только официальный embedded Python 3.12.10, 11 133 606 байт, с проверкой SHA-256.
Версии NuGet и Cargo закреплены lock-файлами. Avalonia публикуется self-contained
с ReadyToRun; Slint — оптимизированный Release с thin LTO.

## Повторение проверок

Из этой папки:

```powershell
./artifacts/python/python.exe -B run-comparison.py --out artifacts/recheck --seconds 30 --startups 10 --cycles 200
./artifacts/python/python.exe -B verify-native.py --exe artifacts/slint/Quote.Slint.exe --out artifacts/native-slint
./artifacts/python/python.exe -B verify-native.py --exe artifacts/avalonia/Quote.Avalonia.exe --out artifacts/native-avalonia
```

Стенд ограничивает только собственные процессы четырьмя логическими CPU. Это не
эмуляция слабого ноутбука. CPU считается относительно этих четырёх CPU, память —
Private Bytes и working set. В основной серии выполняется десять чередующихся
запусков каждого стека и два полных прогона с обратным порядком.

Время UI-команд и сигналы кадров сохраняются отдельно. Сигнал Slint приходит после
рендеринга, Avalonia — через RequestAnimationFrame и фоновую очередь Dispatcher.
Эти точки не идентичны: показатели не доказывают задержку до физического вывода
кадра и не позволяют утверждать, что один интерфейс «в N раз отзывчивее».

Числа, вывод и границы проверки находятся в [RESULTS.md](RESULTS.md).
