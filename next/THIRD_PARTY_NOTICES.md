# Сторонние компоненты Rust-ветки

Сборщик Rust-пакета формирует `licenses/dependencies/inventory.json` по активному `cargo tree` для Windows x64: корни приложения и launcher, зависимости normal/build, без dev и невыбранных optional-пакетов. Включение build-зависимостей сознательно шире состава связанного EXE. В инвентаре указаны версии, выражения лицензий, исходные репозитории, происхождение и SHA текстов. Лицензия собственного проекта этим документом не меняется.

Сборщик копирует LICENSE/NOTICE/COPYING, объявленный `license_file` и файлы каталога LICENSES. Для crates, опубликованных без полного набора текстов, оригиналы сохранены в `licenses/supplemental`: `sources.json` закрепляет Cargo checksum, commit публикации из `.cargo_vcs_info.json`, URL и SHA каждого файла. Среди них сохранены AUTHORS и Chromium notice AccessKit. Сборка проверяет соответствие закреплённому пакету и содержимое; сеть ей для этого не нужна. При смене версии такой supplement необходимо проверить заново.

На снимке 24 октября 2026 обработаны 263 внешних выбранных пакета; у каждого есть текст лицензии (11 пакетов дополнены 27 оригиналами). Это техническая комплектность выбранного графа, а не заключение о соблюдении всех условий распространения или доказательство состава связанного бинарного файла. По умолчанию отсутствие текста останавливает сборку; `-AllowMissing` предназначен только для явного исследовательского отчёта и не используется `Build-package.ps1`. Наличие одного NOTICE не считается наличием лицензии.

## Slint 1.18.1

Для целевого настольного приложения планируется вариант Slint Royalty-free Desktop, Mobile, and Web Applications License 2.0. Он предусматривает атрибуцию; перед распространением бинарного приложения в доступном из основного интерфейса разделе «О программе» должен быть штатный AboutSlint, с сохранением необходимых уведомлений. Источники: [официальный текст](https://slint.dev/agreements/slint-royalty-free-license.pdf), [лицензионные варианты в репозитории Slint](https://github.com/slint-ui/slint/blob/master/LICENSE.md).

Проверен также LICENSES/LicenseRef-Slint-Royalty-free-2.0.md в загруженном пакете Slint 1.18.1. В рабочую оболочку добавлен штатный AboutSlint в разделе настроек. Это ещё не полный лицензионный аудит выпуска. Платный вариант лицензии или изменение лицензии собственного кода не выбраны.

## Остальные компоненты

Для локального установочного кандидата включены тексты Slint Royalty-free 2.0, Apache-2.0 для claxon 0.4.3, MIT для zip 0.6.6 и byteorder 1.5.0 в папке licenses. Это не заменяет полный аудит транзитивных зависимостей перед публичным релизом. Пакет не включает Python, Torch, llama.cpp или веса: они повторно используются из общей папки или устанавливаются отдельно по явному выбору пользователя.

Добавлен claxon 0.4.3 для декодирования готового FLAC в Rust, лицензия Apache-2.0. Версия и контрольная сумма закреплены в Cargo.lock; текст лицензии поставляется в исходном пакете. [Исходный проект](https://github.com/ruuda/claxon), [документация закреплённой версии](https://docs.rs/claxon/0.4.3/claxon/struct.FlacReader.html). Перед распространением включить текст Apache-2.0 и необходимые уведомления в пакет выпуска.

Тексты Rust-зависимостей, включая SQLite/rusqlite, serde, chrono, sha2 и image, собираются автоматически. Перед публичным выпуском остаётся проверить применимость условий к поставляемым компонентам, отдельные Python-среды, медиадекодер, лицензии моделей и комплектных медиа по закреплённым ревизиям. Веса и пользовательские референсы не входят в Rust-пакет или публичный Git.

Проверка сборщика: `./next/Test-notices.ps1` создаёт собственную синтетическую папку под `work/`; покрывает выбор активного графа, REUSE/NOTICE, повреждение/несовпадение pin, недопустимые пути и junction. GitHub workflow запускает её перед упаковкой. Полный инвентарь с файлами получается командой `./next/Collect-notices.ps1 -Output <новая папка> -Offline` при заполненном Cargo cache.
